# Accessible & SEO-Friendly Website

This example demonstrates:

- Semantic HTML5 tags: `header`, `nav`, `main`, `section`, `article`, and `footer`
- ARIA labels and roles where useful
- SEO-friendly title, description, robots, and Open Graph metadata
- A keyboard/tab-navigable contact form
- Visible keyboard focus indicators
- A skip-to-content link
- Accessible required-field labeling
- Responsive CSS
- Reduced-motion support

## Files

- `index.html` — semantic page structure, metadata, navigation, and contact form
- `style.css` — responsive styling and keyboard-focus support

## Run

Open `index.html` in a web browser.
